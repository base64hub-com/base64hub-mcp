# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- e-mail: g@base64hub.com
- or the contact form at https://base64hub.com/contact/

Include the version (`npx -y base64hub-mcp --version`, or the URL for the hosted server) and steps to
reproduce. You will get an answer within a few days. Fixes are released as a new version of the npm
package and the container image, and deployed to `https://mcp.base64hub.com/mcp`.

## Supported versions

Only the latest released version is supported.
